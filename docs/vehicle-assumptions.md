# 차량 사양 가정과 미확인 위험

기록일: 2026-10-26 (Asia/Seoul)

실제 차량을 직접 시험할 수 없어 사진과 관찰 설명만으로 운동 모델을 만들었습니다.
아래 항목은 **확인되지 않은 가정**이며, 시뮬레이터 결과가 실차와 같다고 주장하지 않습니다.
실차 사양이 확인되면 이 문서와 해당 코드를 함께 갱신합니다.

## 조향 구조 (사륜 조향 여부 미확인)

| 항목 | 내용 |
| --- | --- |
| 현재 가정 | 일반 전륜 조향. 후륜축 중심 기준 Kinematic Bicycle Model(임시 기준 모델) |
| 미확인 사항 | 사륜 조향(4WS) 여부, 앞·뒤 바퀴 조향 비율과 위상(같은 방향/반대 방향), 속도에 따른 전환 여부 |
| 4WS일 때 예상 차이 | 반대 위상이면 같은 조향각에서 회전 반경이 더 작고 회전 중심이 차체 중앙 쪽으로 옮겨 감. 같은 위상이면 차체가 비스듬히 평행 이동함. 후진·좁은 통로에서 차체 뒤쪽이 휘두르는 궤적이 달라짐 |
| 교육 영향 | 회전 반경, 차폭 감각, 좁은 통로 통과(시나리오 B) 판단이 실차와 다를 수 있음 |
| 바꿀 곳 | `crates/sim-core/src/vehicle/dynamics.rs`의 `step()` 횡방향 계산(요 각속도와 기준점). 운동 모델은 이 함수 하나로 모여 있어 교체할 수 있음 |
| 확인 방법 | 제조사 사양서, 운영사 문의, 최소 회전 반경과 저속 회전 영상 비교 |

## 구동 방식 (특수 구동 여부 미확인)

| 항목 | 내용 |
| --- | --- |
| 현재 가정 | 한 방향(전방)이 정해진 차량. D=전진, R=후진, 후진 최고 속도는 전진보다 낮음 |
| 미확인 사항 | 앞뒤 구분 없는 양방향 주행 차량인지, 인휠 모터 등 특수 구동인지, 회생 제동 감속 특성 |
| 예상 차이 | 양방향 차량이면 "후진"이 실제로는 반대쪽 전진일 수 있어 최고 속도·카메라·조작 절차가 달라짐 |
| 바꿀 곳 | `config/vehicle.toml`의 `[dynamics]` 속도·감속 값, `crates/sim-core/src/vehicle/state.rs`의 기어 규칙 |

## 치수와 성능 수치

휠베이스, 최대 조향각, 조향 속도, 조향 감도, 최고 속도, 가속·제동·관성·비상 감속도는 모두
`config/vehicle.toml`의 임시값입니다. 충돌 판정에 쓰는 차체 크기(길이 4.2 m, 폭 1.8 m)와
후륜축 위치도 실차 치수를 확인하지 않은 값입니다.
