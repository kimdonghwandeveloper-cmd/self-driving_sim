# 블록 경로 선택 UI 검토

## 병합과 작업 범위

사용자 승인한 Windows 업데이트 브랜치를 main에 병합했고 main/develop을 `96c04ec`로 동기화·push했다. main의 미커밋 gitignore는 공통 Git 폴더 integration-preservation/auto-update-merge-*에 원본/패치를 보관하고 사용자 환경변수 주석과 .env 제외를 유지했다. IDE·Blender·기타 미커밋 파일과 개발 .env는 건드리지 않았다.

새 UI는 최신 develop 기준 `feature/block-route-picker`에서 작업했다. 이 기능은 main/develop에 병합하지 않았으며 push·새 릴리스도 하지 않았다. 기존 sim-v1 배포는 그대로다.

## 구현한 동작

- 지도 클릭은 반경 안의 블록과 허용 방향 후보를 조회한다. 가장 가까운 블록 자동 확정은 하지 않는다.
- 후보의 도로 이름·폭·길이·원본 way·양 끝 노드와 방향 화살표를 확인하고 출발/경유/도착으로 확정한다.
- 출발·도착 교체는 경유를 유지하며 경유는 최대 32개, 한 칸씩 이동·삭제할 수 있다.
- 명시적으로 미리보기를 실행해야 저장·주행할 수 있다. 편집하면 이전 성공 결과를 무효화한다.
- 미리보기는 기존 block-route-v1 준비/재생 검사와 동일한 경로를 사용한다. 저장은 새 파일만 허용하며 기존 파일을 덮어쓰지 않는다. 이름 형식은 영문·숫자·_- 1~64자다.
- 저장 파일은 기존 메뉴 목록과 공통 SimVehicle로 다시 열 수 있다. 기존 route-v1 파일 로더도 유지한다.
- 선택 전에 지역 크기 1.5/5/10 km를 고른다. 경로 길이는 최대 10 km다. 선택 후 영역을 자동 교체해 블록 ID를 바꾸지 않으며, 새 영역은 '새 경로'로 초기화한 뒤 연다.
- 접근 제한은 블록 속성으로 유지하고 연습용 후보에서 제거하지 않는다. 허용 highway·일방통행·회전 제한은 기존 블록 모델 규칙을 따른다.
- 이 블록 저장 판은 고정 OSM 스냅샷용이다. 별도 지역 보정은 자동 적용하지 않는다. 기존 route-v1의 지역 보정 저장/재생은 유지한다.

## 자동 검증

구현 전 핵심 모델과 Godot 화면이 없어 새 시험이 실패하는 것을 확인했다. 이후 별도 detached test 워크트리에서 다음을 확인했다.

- fmt, clippy(--locked --all-targets --all-features -- -D warnings) 통과.
- Rust 460개 통과(core 441, 통합 4, Godot 바인딩 12, CLI 3).
- sim-godot debug 빌드와 최초 import 통과.
- Godot 25종 모두 통과. 새 block_picker_test는 실제 후보 상자 확정, 방향, 미리보기, 저장/덮어쓰기 거부, SimCourse 재생, 실제 차량 이동, 실패한 로드의 상태 보존, 편집 후 결과 무효화, 메인 메뉴의 새 화면 연결을 검사한다.
- 기존 osm_route_drive_test는 기본 메뉴가 블록 UI임을 확인하고 기존 점 화면을 명시적으로 열어 route-v1 호환성을 검사한다. 이 시험의 전국 8도시 성공을 새 블록 엔진의 8도시 성공으로 계산하지 않는다.

## 실제 자료에서 남은 문제 — 병합/배포 완료로 처리하지 않음

- 강남(37.4979,127.0276) 1.5 km: 회전 제한 관계 7365613의 via node 1906756396이 블록 구성 검증을 통과하지 않는다. 원본 PBF/스냅샷과 관계 멤버를 대조해 원인을 밝혀야 한다.
- 엑스포(34.7526,127.7471) 1.5 km: 열기와 509개 블록 표시 성공. way 532526365를 골라도 전체 도로망의 node 794175423에서 `block bends inside joint cut`로 미리보기 실패. 선택과 독립적인 도로망 생성 계약 때문에 무관한 블록을 임의로 빼거나 우회하지 않는다. 곡선 접속 처리와 실제 자료 회귀가 다음 우선 작업이다.
- 실제 엑스포/전국 10 km의 UI→저장→주행, 성능 측정과 사람의 가독성·조작성 검수는 PLAN 6단계로 남는다. 합성 UI 동작을 실제 지도 완주로 표현하지 않는다.

## 수동 확인 방법

`../self-driving_sim-test/godot/project.godot`을 Godot에서 열어 F5 → 경로 지도에 진입한다. 현재 지도 기본값은 새 블록 화면이다. '고급·저장/자료'에서 스냅샷 파일 열기를 선택하고 `testdata/block-picker/graph.osm.json`을 연다.

왼쪽 도로 후보에서 way 10과 1→2를 골라 출발로 확정하고, 오른쪽 way 20의 2→3을 도착으로 확정한다. 미리보기 후 저장 이름을 입력해 저장하거나 주행 시작을 누른다. 같은 이름 재저장은 거부된다. 방향 후보만 바꿨을 때 확정 목록이 바뀌지 않는지, 경유 추가/편집 후 미리보기를 다시 요구하는지 확인한다. 이 시험 자료는 합성이며 실제 도로가 아니다.
