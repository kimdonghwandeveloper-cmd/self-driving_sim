# Simulator v2 — 지도 UI 정리

지도 선택 화면을 좁은 왼쪽 사이드바로 정리했습니다. 출발·도착 지정과 경로 확인·주행 시작은 기본 화면에, 경유·저장·자료·검증 예제는 ‘더 보기’에 있습니다. 주행 버튼은 패널 아래에 고정되고 작은 창에서는 도구 영역만 스크롤됩니다. 경유 순서 ↑·↓ 버튼은 화면에서 제거했습니다.

도로 후보와 선택 목록에서는 내부 노드 ID를 숨기고 이름·방향을 표시합니다. 세부 ID는 툴팁으로 확인할 수 있습니다. 짧은 블록 및 교차로 형상 생성 실패는 기본 화면에 한국어로 설명하며 원본 진단은 툴팁에 남깁니다.

## 사용 순서

1. 지도에서 도로를 클릭하고 후보 방향을 확인합니다.
2. 출발·도착으로 각각 지정합니다.
3. ‘경로 확인’이 성공하면 ‘주행 시작’을 누릅니다.
4. 바로 확인하려면 ‘더 보기’의 ‘엑스포 내부 예제 · 98 m’를 사용합니다. 이 예제에서는 같은 도로·방향을 출발과 도착으로 지정합니다.

## 남은 한계와 다음 작업

- 일부 짧은 블록은 교차로 접속부 생성에 실패합니다. 엑스포 전체 범위의 노드 806285558 문제가 포함됩니다.
- 일부 교차로의 도로 면 자기 교차 문제도 남아 있습니다. 실패한 경로는 주행을 허용하지 않습니다.
- 도로 하나를 클릭해 전방 경로를 자동 제안하는 기능은 이번 범위에 포함되지 않습니다.
- 다음 작업은 짧은 블록·교차로 생성 보완 후 자동 전방 경로 제안입니다.

이번 릴리스는 feature/map-ui-release 커밋을 기준으로 하며 main/develop 병합은 하지 않습니다. 기존 미커밋 주행 화면 변경은 배포 커밋에서 제외하고 보존합니다.
