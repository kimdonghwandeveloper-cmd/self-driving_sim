# 지역 보정 후보 통로 조사표 (양식)

PLAN 4-11a의 실제 지역 보정(`data/map-patches/<id>.toml`)을 만들기 **전에** 채우는 증빙 문서다.
통로 하나당 이 파일을 `docs/map-patches/<보정 ID>.md`로 복사해 채운다. 보정 TOML보다 먼저 만들고,
TOML의 `source_description`에는 이 문서 경로와 요약만 적는다.

- 보정 형식(`map-patch-v1`)은 정해진 키 외의 키를 거부한다. 확인 시각·검토자·기준 OSM 판본·시간대·차량 종류 제한은
  형식에 칸이 없으므로 **이 문서에만** 남긴다.
- 직접 측정하지 않은 값은 "실측"이라고 쓰지 않는다. 추정이면 방법과 예상 오차를 함께 적는다.
- 모르는 칸은 비우지 말고 "미확인"이라고 쓴다. 미확인 칸이 있으면 9절 판정에 반영한다.
- 사진·영상 원본은 저장소에 넣지 않는다(개인정보·재배포 권한). 보관 위치만 적는다.

### 접속 후보(anchor)

양쪽 끝마다 한 줄씩 적는다. OSM 노드에 바로 붙으면 `osm_node`, way의 노드 사이에 붙으면 `osm_way` + 인접 노드 쌍.

| anchor ID | 종류 | OSM node ID 또는 way ID | 인접 노드 쌍 (way일 때) | OSM 좌표 | 확인 좌표 | 거리(m) |
| --- | --- | --- | --- | --- | --- | --- |
| | osm_node / osm_way | | [ , ] | | | |
| | osm_node / osm_way | | [ , ] | | | |

- [ ] 인접 노드 쌍이 실제로 그 way 안에서 이웃인지 확인
- [ ] 연결할 OSM 도로의 `highway`가 경로 탐색 허용 종류(`config/road_graph.toml` `allowed_highways`)인지 확인
- [ ] 근처에 헷갈릴 만한 평행 도로나 비슷한 `service` way가 없는지 확인

## 9. 판정

해당하는 것 하나에 표시한다.

- [ ] **verified**: 존재, 양쪽 접속, 통행 조건, 출처·재배포, 형상·가장 좁은 폭이 모두 확인됨. 시간·차량 제한 없음.
- [ ] **provisional**: 존재는 확인됐지만 일부가 불명확함(불명확 항목: ). 개발자가 명시적으로 켤 때만 쓰고 배포하지 않는다.
- [ ] **작성 보류**: 아래 중단 조건 중 하나 이상 해당 (해당 번호: )

### 중단 조건

다음 중 하나라도 해당하면 보정 파일을 만들지 않거나 `provisional`로 제한한다.

1. 최신 OSM에 같은 통로가 이미 있음 (0절)
2. 양쪽 OSM 접속점을 확정할 수 없음
3. 상시 차단기가 있고 통과 권한이 불명확함
4. 보행자 전용일 가능성이 있음
5. 시간대·차량 종류 통행 제한이 있음 (v1 형식으로 표현 불가)
6. 형상 근거 자료의 파생·재배포 권한이 불명확함
7. 가장 좁은 폭을 확인할 수 없음
8. 임시 행사 통로 또는 공사 동선임
9. 실제 좌표와 OSM anchor 오차가 20 m(`max_error_m` 상한)를 넘거나 GPS 흔들림으로 설명되지 않음
