# 여수 엑스포 OSM 배경

- [OSM 원본 다운로드 범위](https://api.openstreetmap.org/api/0.6/map?bbox=127.7460,34.7480,127.7600,34.7590). Blender 5.3 및 Blosm 2.8.0으로 생성.
- `testdata/yeosu-expo/course.toml`과 같은 원점(34.7509700, 127.7493575)과 미터 단위를 사용한다. Godot +X는 동쪽, +Z는 남쪽이다. 배치 변환은 필요 없다.
- 건물 높이와 도로 폭 일부는 근사값이며 지형은 평면이다. GLB는 표시용이고 주행 노면·충돌 형상은 기존 코스에서 제공한다.
